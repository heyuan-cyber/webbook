## 2. 关键设计：同一份 DOM，只改一个属性

```html
<!-- 只改这一个属性 -->
<div class="site-body" data-preset="lively">

<!-- 元素自己声明"我属于哪一档" -->
<div class="hero-grid" data-par-depth="0.4"></div>     <!-- lively+ 才有视差 -->
<div class="pet-dock fx-playful"> … </div>              <!-- 只有 playful 显示 -->

/* CSS 门控 —— 三行 */
[data-preset="quiet"]  .fx-lively,
[data-preset="quiet"]  .fx-playful,
[data-preset="lively"] .fx-playful { display:none !important }
```

**三档之间不是三套代码，是三份 `Interaction[]`。**

JS 侧对应六阶段的约束③：挂监听前先判断
`decoOff() || presetOf(el) === 'quiet' || !visible(el)` 就直接 return ——
**关闭时根本不注册**，不是"注册了但不执行"。

## 3. 三档的边界

| | 新增 | 合成层 / 监听 | 移动端 |
|---|---|---|---|
| **安静**（默认） | 只有功能型 + 区块入场 | 无新增合成层；只有滚动监听 | 无风险 |
| **有活力** | 视差 / 光晕 / 倾斜 / 乱码 | 视差 3 层 + 光晕 1 层；指针监听 3 处，rAF 节流 | ≤720px 全部不挂载 |
| **玩心** | 宠物 / 磁吸 / 涟漪 | 再加宠物 1 层 + 涟漪临时节点 | 宠物 ≤1100px 不显示 |

**安静档必须能独立成立**，不能是"别档砍掉动效后的残骸" —— 因为 `prefers-reduced-motion` 用户看到的就是它。

---

## 4. 访客的出口：为什么放页脚

六阶段约束②说「访客能一键关掉全部装饰型」，但**现在代码里完全没有这个出口**。三个位置的取舍：

| 位置 | 结论 |
|---|---|
| **页脚文字链** | ✅ **推荐**。不占视觉、能被找到、不打扰。访客读到页脚时本来就在做"这次浏览结束了"的判断 |
| 右下角小图标 | ✗ 又是一个常驻浮层，还要和宠物抢位置；而且"关掉动效"的按钮出现在动效区里有点自相矛盾 |
| 不给开关 | ✗ 等于把责任推给用户的系统设置。想安静读文章的人不该为此去改操作系统 |

点击后：① 立即安静（不等刷新）② toast 确认 + **可撤销** ③ 写 `localStorage`，**按站主分开记** ④ 页脚那行字变成「恢复页面动效」，位置不变。

## 5. 两侧的边界

| 谁 | 能决定 | 不能决定 |
|---|---|---|
| **站主** | 预设档位、逐条开关、参数值（在六阶段定的上限内）、访客开关的行为 | ❌ 不能关闭功能型交互（阅读进度、站点脉搏）—— 那些承载信息 |
| **访客** | 一键关掉全部装饰型；随时恢复 | ❌ 不能开启站主没开的交互（避免"我明明关了它又冒出来"） |
| **系统偏好** | 优先级最高：`prefers-reduced-motion` 开着 = 访客永久选择安静 | — |

---

## 6. 参数规范的一句话总结

每条效果的「类型 / 时长 / 缓动 / 上限 / 断点 / 降级」**就是 `catalog.ts` 里的字段**。
规范不是文档，是类型的注释 —— **写不进类型的那部分，半年后一定会被绕开**。

所以站主只能在那几档里选，不能自由填数：
开放自由输入，三个月后就会有人填出 40° 的倾斜。

### 反面清单（七条）

跟随光标 · 0→N 数字滚动 · 超过一处无限循环 · 进页面时的全屏过场 ·
声音默认开 · 把"关掉动效"当降级残骸 · 让站主填自由数值
