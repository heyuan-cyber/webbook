参数规范

前两页是「长什么样」，这一页是「凭什么是这个数」。 每条效果的时长、缓动、参数上限、断点、降级行为都写在这里 —— 这些上限要写进类型，不是写在注释里。

① 时长阶：6 档，每档一个职责

点每一行的「播」听节拍。现在的实现只有 3 档（120 / 180 / 260ms）。

--dur-190ms　按压、勾选、微反馈
--dur-2140ms　hover / 选中 / 颜色切换（最高频）
--dur-3200ms　菜单、面板、toast 进出
--dur-4300ms　区块入场、共享元素、抽屉
--dur-5480ms　连线生长、大范围位移、涟漪
--dur-6760ms　首屏编排、一次性仪式（用一次就够）

两条硬规矩：① 超过 300ms 的动效不许出现在高频操作上（切 tab、勾选、hover）； ② 时长不随数据量增长 —— 列表 3 项还是 12 项，总时长要一样，靠错峰步长反向补偿。

② 缓动：5 条曲线

--ease-out cubic-bezier(.16, 1, .3, 1)
进入用。快起慢收 —— 元素「到位」而不是「飘过去」
--ease-io cubic-bezier(.4, 0, .2, 1)
状态互换用（hover / 颜色 / 顶栏 morph）。两端都不突兀，即现在的 --ease
--ease-spring cubic-bezier(.34, 1.42, .5, 1)
「弹一下」用。曲线越过终点再回来。只用在 ≤200ms 的小元素，否则显得廉价
--ease-stage cubic-bezier(.22, 1, .36, 1)
空间移动专用（视差落位、光标光晕）。比 --ease-out 更平 —— 空间位移有一点回弹就会晕

③ 位移与错峰

位移距离

--move-12px　按压下沉
--move-26px　提示、气泡
--move-312px　区块入场（最常用）
--move-424px　侧滑面板

位移越大、时长越长：12px 配 300ms，24px 配 400ms 以上。 现在 .reveal 用 14px、App.tsx 页面转场用 8px、按钮按下无位移 —— 三个数互相没有关系。

错峰步长

--stagger-128ms　密集列表（≥12 项）
--stagger-244ms　卡片网格（4~11 项）
--stagger-370ms　分节标题（≤4 项）

必须封顶：delay = min(index, 8) × step。 否则 20 项 × 28ms = 560ms，最后一项会明显「迟到」。

④ 逐条效果规范

「上限」这一列是要写进类型的硬约束，不是建议值。

⑥ 决策：我想要某个效果，该用哪个

你想要的感觉用这个为什么不是别的
「内容是一段段出现的」stagger + rise不是 typewriter —— 逐字打出来在中文里很慢，而且正文用它会打断阅读
「页面有纵深」parallax不是 tilt —— 整页纵深靠分层速率；tilt 是单个元素的事
「这个东西能被拿起来」tilt 或 magnetic卡片用 tilt，按钮用 magnetic。反过来会让人点不准
「页面注意到我了」spotlight不是 cursor-follow —— 跟随光标是最廉价也最烦的做法（六阶段已经论证）
「站主很有个性」character 或 scramble不是换配色 —— 配色是全局的，个性和"会动的小东西"绑定更紧
「这个数据是真的」heatmap不是 pop 计数 —— 数字滚动会被误读成实时数据
「读到哪里了」morph（进度线）这是功能型，任何档位、任何降级下都必须保留

⑦ 反面清单

跟随光标　把「有生命的邻居」变成「黏着鼠标的挂件」。每帧都在动 = 持续索取注意力 + 持续占用合成层。
0→N 的数字滚动　只是拖时间。用户要的是最终值，不是看它数数。
超过一处无限循环动画　一个页面同时有两个以上一直在动的东西，注意力会被撕开。宠物呼吸已经是那一处配额。
进页面时的全屏过场　访客是来看内容的，不是来看转场的。首屏动效总时长 ≤760ms 且不阻塞内容出现。
声音默认开启　声音必须默认关，且要有明显的开启入口。
把「关掉动效」当成降级残骸　安静档必须能独立成立 —— prefers-reduced-motion 用户看到的就是它。
让站主填自由数值　参数只能是六阶段定的那几档。开放自由输入，三个月后就会有人填出 40° 的倾斜。

这一页的每一条都能对应到六阶段的 catalog.ts： 「效果 / 类型 / 时长 / 缓动 / 上限 / 断点 / 降级」就是那个类型定义里的字段。 规范不是文档，是类型的注释 —— 写不进类型的那部分，半年后一定会被绕开。
