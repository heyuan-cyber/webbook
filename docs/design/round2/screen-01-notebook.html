战斗演出编辑器架构设计

2026-09-2412 个块2 条连线a3f19c2

目标

把战斗演出从「帧驱动」改成「时间轴 + 事件驱动」，编辑器侧只描述演出意图，运行时负责插值。这一段是可编辑的块，双击空白处插新块。

标注

时间轴精度定在 1/60 秒；编辑器只存关键帧，插值曲线随轨道保存。

分层

  • 轨道层 — 纯数据，可序列化，进 git
  • 求值层 — 每帧从轨道采样，产出姿态
  • 表现层 — 只消费姿态，不反向写
