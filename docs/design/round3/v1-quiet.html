「静」Quiet Craft

把装饰全部拿掉，只留结构。动效只出现在状态变化的那一刻 —— 没有入场动画、没有错峰、没有视差。它的目标不是「好看」，是写作三小时之后仍然不打扰你。

战斗演出编辑器架构设计

2026-09-2412 个块 2 条连线a3f19c2

把战斗演出从「帧驱动」改成「时间轴 + 事件驱动」，编辑器侧只描述演出意图，运行时负责插值。

标注

时间轴精度定在 1/60 秒；编辑器只存关键帧，插值曲线随轨道保存。

分层

01
轨道层 — 纯数据，可序列化，进 git
02
求值层 — 每帧从轨道采样，产出姿态
03
表现层 — 只消费姿态，不反向写

正文 15px / 行高 1.9 / 行宽 720px。这一版把「块」的画框也去掉了 —— 用分割线代替卡片。

核心差别 无卡片阴影、无网格底纹、无背板模糊（backdrop-filter 全部关闭）· 正文用分割线而不是盒子 · 按钮不再有渐变

这一版的动效：只有三条规则

① 选中态滑动

唯一保留的「位移动画」。用 140ms 的轻微过冲（--ease-spring）告诉手指「点到了」—— 点上面的 tab 试试。其他所有选中态都是纯颜色切换，没有位移。

时间轴精度定在 1/60 秒
插值曲线随轨道保存
② 勾选与删除线

勾选框用 140ms 的 --ease-spring 弹一下；删除线用 width: 0 → 100% 划过去，而不是瞬间出现。这是「静」版唯一允许的愉悦感。

③ 保存状态 morph点我切换

同步中 → 已同步：底色与文字色用 200ms 交叉，图标原地替换。不做弹出、不做位移 —— 状态提示不该抢注意力。

战斗演出编辑器架构设计
时间轴 + 事件驱动，编辑器只描述意图。
④ 骨架 → 内容

骨架淡出与内容淡入同时进行（各 200ms，交叉而非接力），避免出现「先空一下再出现」的闪烁。

代价与风险

项说明
不做的动效列表错峰、页面转场、视差、镜头飞行、共享元素 —— 全部没有。列表一次成型
省下的合成层最少；长列表滚动不掉帧；写作时零干扰
风险第一次打开会觉得「有点朴素」。需要用排版（字号、行高、字重、留白节奏）而不是动效来撑住质感
和现有实现的差距要去掉 .card 阴影、.stage-grid、topbar 的 backdrop-filter、btn-primary 的渐变；.reveal（0.5s 上移）在这一版要关掉
系统当前：正常

点左边按钮可以在同一台机器上切换动效开关，直接看降级后的样子（真实用户由系统偏好控制）。
