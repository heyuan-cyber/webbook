01

三个方向

同一套信息架构，三种视觉语言。点开任一方向看完整设计稿。

方向一 · 墨金 Warm Editorial

在你现在的气质上做减法，风险最低

保留暖金与暗色，去掉大范围玻璃模糊和极光动效；把画布从冷蓝改回暖石墨 + 金色连线。写作时背景终于安静下来。

  • 侧栏可拖宽 · 缩进 10px/级 · 面包屑补偿
  • 顶栏收敛为 面包屑 + ⌘K + 账号
  • 24 个线性 SVG 图标替换全部 emoji
查看设计稿

方向二 · 纸墨 Ink & Paper

翻成浅色纸感，差异最大

纸白底 + 墨黑字 + 朱砂点色，层级靠细分割线和留白而不是卡片阴影。适合白天长时间写文档，暗色留作夜间模式。

  • 阅读与写作对比度最好
  • 画布改为"网格纸 + 墨线"表达
  • 代价：不再是"暗黑高级"观感
查看设计稿

方向三 · 蓝图 Blueprint

技术舱：网格、等宽、精密对齐

冷石墨底 + 青色强调（青色这次是全局主色，不再只是画布私用）。元数据用等宽字体，高信息密度但强对齐。

  • 面向"技术文档 + 知识图谱"的场景
  • 8px 基线网格，所有面板同一套仪器排版
  • 与方向一共用 80% 组件结构
查看设计稿

怎么选（一句话版）

  • 想稳：方向一。你会觉得"还是 WebBook，但终于安静了"。
  • 想变：方向二。白天写文档体验最好，但要接受整体变浅。
  • 想贴工程：方向三。你现在的目录（渲染 / Gameplay / 工具链）很适合蓝图语言。
  • 混搭也行：最省事的组合是 方向一的外壳 + 方向三的画布 —— 告诉我取哪几块即可。

03

关键数字（审计摘要）

这是"看起来像两个 App"的量化原因。完整证据见 UI-REFRESH-AUDIT.md。

0 / 188
TOKEN LEAK

--fs-* 用了 0 次，字号硬编码 188 处

11 种 px 字号里，12px 出现 58 次、13px 46 次、11px 30 次 —— 三个角色没有名字。改一次要动几十处。

33
SILENT FALLBACK

var(--token, #hex) 兜底会把画布变蓝

画布/图谱层用 #38bdf8 冷蓝 + #334155 slate 写在兜底值里，且 --muted 是拼错的 token 名（真名 --text-muted），所以 #94a3b8 永远生效。

7 级
SIDEBAR DEPTH

300px 侧栏遇上 7 级缩进

从你运行中的 /app 读到真实目录最深 7 级（缩进 8 + depth×14 = 106px），只剩 190px 放文字和 5 个工具按钮。

48
EMOJI AS ICONS

emoji / 字符当图标

📁📄 ＋❏☑✎🗑 ☰ ⠿ ✕ 🤖 🛠 ⟳… blockFactory.ts 甚至把中文词「立方」当图标。跨平台字形不同、不能跟随主题色。

1 / 8
NAV COVERAGE

只有 /app 有外壳

AppShell 只被 UserApp.tsx 使用 —— /blog、/blog/u/*、/app/circles、/admin 都没有侧栏、顶栏和 ⌘K。

~19%
DEAD CSS

首页背了六代，约 500 行死代码

v4 / v5 霓虹 / io-* / blog-home-v2 / io-site / Swiss 全在同一个文件里。改"卡片样式"改第一处定义不会生效（.io-card、.btn-sm 都定义了两遍）。

04

三个方向都要修的（不依赖选择）

  • 补全并接入 token：--fs-* 补 11/12/13px 三档，--space-* 补 6/10/14/18px，加 --radius-pill、--stage-bg、--on-media、--handle，把写了 7 遍的 0 4px 14px rgba(0,0,0,.35) 收成 --shadow-md。
  • 删掉 33 处 var(--token, #hex) 兜底，并把 --muted 改名 --text-muted。这是"画布不会某天突然变蓝"的保险。
  • 统一图标：24 个 inline SVG，全部 aria-hidden + 父级 aria-label。
  • 导航收口：让 /blog、/app/circles、/admin 共用顶栏 + ⌘K；顶栏加 active 态；「后台」只对 admin 显示。
  • 移动端补底部导航（笔记 / 任务 / 社区 / 我的）+ 悬浮「＋新建」。
  • 侧栏可读性：宽度可拖（默认 280px 存 localStorage）、缩进 14→10px、当前路径自动展开、hover-only 工具条改为"常驻低对比"（修键盘不可达）。
