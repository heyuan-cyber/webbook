交互实验室

13 条可点的交互。每条都标了触发器、效果、成本、降级行为， 并且分成「功能型」和「装饰型」—— 右上角那个开关会把装饰型全部关掉，功能型留着。 这就是把「约束」做成可验证的东西，而不是写在文档里的一句话。

功能型 承载信息，关掉会丢东西　 装饰型 表达过程，关掉只少了感觉
① Hero 视差装饰型
何源
trigger · scrolleffect · parallax3 层

背景网格 / 词标 / 分隔线三层不同速率。速率差控制在 0.35×–1.8×，超过 2× 会让人感到"页面散了"。滚动这个 demo 所在的页面区域就能看到。

降级：层位移归零，三层重合 → 视觉上等同静态海报
成本：passive scroll + rAF 节流，只写 transform

② 光标光晕装饰型
把鼠标移进来
trigger · pointereffect · spotlight

一圈柔光跟着光标。用 240ms 缓动跟随，不是实时跟手 —— 实时跟手会有"黏住鼠标"的廉价感。只改 CSS 变量，不触发重排。

降级：光晕隐藏（不占层）
成本：pointermove + rAF 节流；离开即停止写入

③ 卡片倾斜装饰型
悬停卡片
trigger · hovereffect · tilt≤6°

3D 倾斜。上限 6° —— 超过 10° 文字会开始变形、可读性下降。透视 700px（小于 500px 会像广角镜头一样夸张）。

降级：卡片保持水平
成本：pointermove；离开时清 inline transform

④ 磁吸按钮装饰型
trigger · pointer:neareffect · magnetic≤8px

光标进入 120px 半径时按钮被"吸"过去，位移上限 8px，离开用 --ease-spring 弹回。只在主 CTA 上用 —— 每个按钮都吸会让人找不准。

降级：按钮不动
成本：pointermove；必须保留原生点击热区，位移只改视觉

⑤ 词标乱码归位装饰型
何源
trigger · hovereffect · scramble一次性

鼠标移到词标上，字符短暂乱码再逐位归位 —— 读起来像"重新签名"。每个字错峰 26ms，总时长 ≈ 300ms。同一次悬停只播一遍，不循环。

降级：不触发，文字保持原样
成本：纯文本替换；不涉及动画帧

⑥ 列表错峰入场装饰型
战斗演出编辑器架构设计
光照管线笔记
战损贴花使用指南
GS 性能排查工具
trigger · scroll:entereffect · stagger

步长 44ms、位移 12px、单条 300ms。必须封顶：delay = min(index, 8) × step，否则第 20 项要等近 1 秒。

降级：内容一次成形
成本：IntersectionObserver 一次，播完即断开

⑦ 站点脉搏功能型
悬停任意一格
trigger · hovereffect · data-viz零新字段

60 天更新热力。数据直接来自已有的 posts[].updatedAt，不需要任何新字段，也不需要请求。

降级：颜色仍然保留（它是信息不是过程），只去掉 hover 放大
成本：纯 CSS，无 JS

trigger · scroll:entereffect · pop

300ms 轻微过冲（先到 95.5% 再回 100%），三个数字错峰 70ms。刻意不做「从 0 滚到 2140」的计数动画 —— 那只是拖时间，用户要的是最终值。

降级：数字直接显示
成本：一次性，无监听

⑨ 阅读进度功能型

战损贴花使用指南

换装流程里第一次看到战损贴花的人，通常会问三个问题：怎么预览、配置写在哪、贴图尺寸在哪改。

运行后使用 GM 命令，使用后会小卡一两秒 —— 这是贴图首次上传，属正常。

配置放在 DT_BattleDecalTexture.uasset：一行是一种武器类型和一种材质的贴图配置。

进战斗前先确认三件事：武器类型、材质类型、贴图数组非空。

如果要验证贴花在移动中的表现，建议开一局自定义再拖动镜头观察。

贴花不显示 → 先查上面三条；显示但位置偏 → 检查挂点名称。

trigger · scroll:progresseffect · indicator

这是功能型：它告诉读者"还剩多少"。滚动上面的正文试试 —— 即使把装饰型全关掉，它仍然工作。

降级：保留（只把 80ms 过渡改成 0）
成本：passive scroll + rAF 节流

trigger · scroll:directioneffect · morph

⑪ 隐藏段落功能型
你在链接里带了 #secret —— 这段只有拿到链接的人看得到。站主可以拿它放"只发给某个人"的话。
trigger · url:hasheffect · reveal

纯前端、零后端：URL 里带特定 hash 就揭示一段平时不显示的内容。注意它不是权限控制 —— 内容仍在 HTML 里，只是默认隐藏，别放真隐私。

降级：保留（这是内容不是装饰）
成本：读一次 location.hash

⑫ 时间彩蛋功能型
用代码造作品，也把背后的思考写下来。
这么晚还没睡。
本地时间 00:00–05:00 触发
trigger · clockeffect · copy-swap

不做动画，只换一句文案 —— 成本最低、效果最好的一条。同类还有：整点、节日、纪念日、第 N 次来访。

降级：保留（只是文案）
成本：读一次 Date

把「约束」变成可验证的东西

右上角那个开关就是本阶段的核心论点：交互必须能被分类，才能被批量降级。 分不清「功能型 / 装饰型」的交互层，最终只能在 prefers-reduced-motion 里一刀切全关 —— 那会连进度线一起砍掉。

约束做法在实验室里怎么验
可分类每条交互声明 kind: 'functional' | 'decorative'右上角开关 —— 装饰型全灰掉，功能型照常
可关闭访客级开关，记 localStorage同上（这里的开关不持久化，线上会）
不挂空监听关闭时根本不注册监听，而不是"注册了但不执行"关掉后指针移动不会再写 CSS 变量
不用常驻 rAF只有滚动 / 指针事件里 rAF 节流；空闲即停⑨⑩ 的滚动，②③④ 的指针
移动端有替代触屏没有 hover → 依赖 hover 的交互在 ≤720px 直接不挂载窄屏打开本页，②③④⑤ 无反应（这是对的）
不挡内容装饰层 pointer-events:none；位移只改视觉不改热区④ 磁吸按钮位移 8px，点击热区不动
首屏不阻塞交互层在 hydration 之后挂载；无 JS 时全部静态禁用 JS 打开本页，13 条都还在（只是不动）
