## 1. 一句话

**一个带博客展示和私密朋友圈的个人笔记本，后端用 GitHub 私有仓 + Cloudflare Worker 实现零成本部署。**

## 6. 安全边界

| 数据级别 | 谁可读 | 对应 API |
|----------|--------|----------|
| public | 互联网任何人（无需登录） | `/api/public/*` |
| circle | 该圈子成员（登录 + JWT） | `/api/circles/*` |
| private | 仅自己（登录 + JWT + userId 匹配） | `/api/notes/*` |
| admin | 管理员（登录 + JWT + 邮箱匹配） | `/api/admin/*` |

**已知风险（见 `/docs/DEPLOY-GUIDE.md` 安全章节）：**

- legacy 兼容层：多用户场景下旧路径数据可能被新用户读到
- 无公开 API 限流
- 公开 feed 暴露用户邮箱
- `link-preview` 未鉴权（SSRF 风险）
